# Valiant Quest Manager
This is a CLI application for managing a campaign in the TTRPG Valiant Quest. 

## Planned Features:
- [ ] Text based user interface for managing a campaign
- [ ] Save and load campaigns (stored as a json file)
- [X] Track and give information about the current location
- [X] Generate new locations on demand
- [X] Travel to and explore locations
- [ ] Generate loot
- [ ] Generate market goods
- [ ] Check for random encounters during travel

## For The Future:
- [ ] Generate dungeon floors on the fly
- [ ] Generate named monsters
- [ ] Generate and display stats for monsters in an encounter
- [ ] Faction management
